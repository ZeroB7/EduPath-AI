# EduPath AI

EduPath AI is a personalized remedial and adaptive learning platform.

## Main Goal

This project analyzes learner assessment results to detect mastery level and recommend remedial learning materials.

## Core Features

- Assessment Module
- AI Diagnostic Engine
- Remedial Recommendation
- Progress Tracking

## Dataset

- Open University Learning Analytics Dataset (OULAD)

## Tech Stack

- Python
- Pandas
- Scikit-Learn
- Flask
- SQLite
